# Sañudo Artesania BCN

Propuesta editorial para el taller Sañudo del Poble Espanyol, centrada en cursos de marroquinería, experiencias y encargos artesanales.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm test
```

El proyecto está preparado para importarse desde GitHub en Vercel.
